The friendly version

No tech background needed. Here's what this is, in everyday words.

So, what is it?

Think about the things you see on your computer all day without really noticing them: the bar with the clock, the place where you search for apps, the little pop-ups that tell you a message arrived. All together, those pieces are called a “desktop shell”. It's the part of the computer you look at and click on, around your apps.

Windows comes with its own. II for Windows gives you a different one, with a different look and a few extra tricks, while your apps and files stay exactly the same.

Where does it come from?

It's based on illogical-impulse, or “ii” for short: a popular desktop that a developer called end-4 made for Linux, which is a different operating system from Windows.

This project takes that same desktop and makes it run on Windows, keeping it as close to the original as it can. Almost everything you see was designed by end-4; this port is the part that makes it work on Windows.

What you get

  • A bar at the top of the screen that shows the song you're playing, the clock, your battery and the small icons of apps running in the background.
  • A side panel with quick switches like Wi-Fi, Bluetooth and night light, plus your notifications and a calendar.
  • A search box: tap the Windows key on its own and type. It finds apps, files, emoji and things you copied, searches the web, and can lock or restart the PC.
  • Colors that match your wallpaper. Pick a new picture and the whole desktop changes its colors to go with it.
  • Move a window by holding the Windows key and dragging it from anywhere, and resize it the same way with the right mouse button.
  • Separate desktops for separate things, like one for work and one for games, with an overview that shows them all at once.
  • Handy extras: grab a piece of the screen, copy the text out of a picture, record your screen, or translate the words you're looking at.

What happens when I install it?

You download one small program, the setup. Before it changes anything, it shows you a page that lists every single thing it will do, and you have to scroll through it first. No surprises.

It installs everything into your own Windows account, so it doesn't ask for an administrator password, and your personal files aren't touched. The usual Windows taskbar is still there: it just hides until you move the mouse to the bottom of the screen.

Is it free?

Yes, completely. It's free and open source, which means anyone can read the “recipe” it's made from and check what it does.

What if I don't like it?

You remove it like any other app: Settings, then Apps, then Installed apps, then “illogical-impulse (ii-windows)”, then Uninstall. It puts your wallpaper, light or dark mode, accent color and taskbar back the way they were before.

A few things to know first

  • It's experimental. Most things work, some are still rough, and a few haven't been tried on every kind of computer yet, like laptop batteries and screen brightness.
  • Some keyboard shortcuts change while it runs. Pressing the Windows key on its own opens ii's search instead of the Start menu. Press the Windows key and / together to see the full list.
  • The first time you open the setup, Windows may show a blue box saying “Windows protected your PC”. That's because the setup isn't signed yet. Click More info, then Run anyway, but only if you downloaded it from this page or from the project's GitHub.
  • Something broke? Tell the project on GitHub. Please don't ask end-4 or Microsoft about it: they don't make this port.

The technical version

Two forks, a native Windows backend behind the APIs ii already uses, and a per-user setup. Everything here comes from the project's own docs.

Architecture

  • nunreasonable/quickshell · windows Quickshell (based on upstream 0.3.1) with its core made portable and a native backend in src/windows/. Linux-only modules are compiled out; pure-QML shims keep the same import URIs until a native C++ module with that URI replaces them.
  • nunreasonable/dots-hyprland · ii-windows ii's history split out of the dots repository with git-filter-repo, so upstream changes still merge. Services keep their public properties and swap only the implementation, so most modules are untouched; every Linux command is mapped to a native API or switched off cleanly. A Platform.isWindows singleton guards Linux-only startup code, and Windows-only singletons are reached lazily through WindowsNative.qml, so the same files still load on Linux.
  • nunreasonable/ii-windows Packaging and the setup: deploy, package and release scripts, the Tauri installer, and the Windows builds of the helpers (SongRec's recognizer and MicroTeX).

Windows and layers

  • WinPanelWindow Replaces PanelWindow + WlrLayershell. Panels are AppBars: screen space is reserved through the shell and released on hide or exit. Z-bands, DWM attributes, and input masks applied through a low-level mouse hook.
  • Direct3D 11 Qt Quick picks the D3D11 backend (GraphicsInfo.api == 4); translucent frameless windows work as-is.
  • Window tracker SetWinEventHook-based tracker shaped like hyprctl JSON, backing HyprlandData and ToplevelManager. The WinEvent hooks run on their own thread, drop cursor and caret events and deliver window events in batches.
  • Quickshell.Hyprland Workspaces are Windows virtual desktops (registry, IVirtualDesktopManager and VirtualDesktopAccessor), with Hyprland.dispatch mapped to native actions. HyprlandFocusGrab becomes outside-click and foreground-change dismissal.
  • Win + drag Win + drag moves a window and Win + right drag resizes it (super_drag.cpp): with tiling it swaps tiles and drags the split live, and it keeps the grabbed point proportional across monitors with different scaling. Fullscreen and elevated windows are left alone; UIPI-blocked WM_CLOSE falls back to WM_SYSCOMMAND/SC_CLOSE.
  • DesktopLayer By default Windows draws the wallpaper and ii keeps it in sync both ways (it watches HKCU\Control Panel\Desktop, since IDesktopWallpaper sends no WM_SETTINGCHANGE); only the desktop widgets live in the desktop, in their own window above SHELLDLL_DefView with the input mask as the window region. windowsPort.ownWallpaper brings back ii's own wallpaper with parallax, reparented under WorkerW (on 24H2 and later, inside Progman, below SHELLDLL_DefView). Windows inside the desktop don't get WM_DPICHANGED, so they're recreated when the display scale changes.

Tiling and blur

  • Tiling (dwindle) Optional native dwindle layout, one per (virtual desktop, monitor), with no external window manager. Driven by the dispatchers ii's keybinds already use: togglefloating, togglesplit, movewindow, splitratio. Dialogs, fixed-size windows, elevated windows and listed apps stay floating; turning it off puts every window back where it was.
  • Blur · Windows 11 A Windows.UI.Composition host-backdrop window, unfocusable and click-through, under each panel, with rounded shapes taken from the item tree and rules from layerrules.json (Hyprland's layer rules, converted).
  • Blur · Windows 10 SetWindowCompositionAttribute blur-behind, one window per shape, because that blur ignores SetWindowRgn.
  • QS_WINDOWS_BLUR=0 Blur only exists while ii's transparency is on, and turns off with Windows' transparency effects off, high contrast, energy saver or this variable.

Input and session

  • Spotlight A lone Super press opens a search-only Spotlight (apps with their own entry icons, files, clipboard history, emoji, system actions and web search); Super+Tab opens the workspaces with their windows. Settings > Services > Search switches back to the previous overview.
  • Cold start On a VM held to two slow cores and a slow disk the bar shows in about 2 s (0.6.1: about 5 s; 0.5.0: about 43 s). A scan cache (qmlscan.bin) skips the ~600 QML files whose size and date haven't changed, and deploy and setup keep file times so the cache survives updates. ii ships a precompiled QML bytecode bundle, creates the bar first and gates the rest behind its first frame: the virtual desktop DLL, the initial window list, the AppBar reservation, network, media, Bluetooth, extra audio devices, the tray and the Windows 11 blur compositor. Slow jobs (desktop entries, thumbnails, WMI brightness probes) run on a small dedicated thread pool, theme and translations arrive before the bar, and nothing spawns PowerShell or cmd while starting. The input hooks opt out of Windows 11's background-process throttling.
  • RegisterHotKey + WH_KEYBOARD_LL Global shortcuts, with a low-level keyboard hook for the lone Super key. Binds load only in the shell.qml process (settings and welcome don't register them); users edit keybinds.json in %LOCALAPPDATA%\illogical-impulse.
  • Low-level mouse hook Runs at high priority for input masks and the hover-only taskbar. It decides on its own when a mask has to change and only wakes the UI thread then; events from irrelevant windows are dropped before they reach it. qs log reports input that reached the hooks late.
  • Taskbar Auto-hide is turned on while ii runs and restored on exit. An EVENT_OBJECT_SHOW WinEvent in Explorer's process re-hides it as soon as an app opens (at most 10 times per second).
  • -n / --no-duplicate Shortcuts, the Run entry and setup launches start a single instance.
  • Session LockWorkStation, ExitWindowsEx, InitiateShutdownW and SetSuspendState; idle inhibit through PowerCreateRequest / PowerSetRequest; SendInput in place of ydotool.

Crash handling

  • One funnel SetUnhandledExceptionFilter, _set_invalid_parameter_handler, std::set_terminate and signal(SIGABRT) all lead to the same handler.
  • MiniDumpWriteDump MiniDumpWithDataSegs | MiniDumpWithThreadInfo into the instance's crash directory, then the live log and a report.txt next to it (skipped on stack overflow).
  • CreateProcessW Relaunches the shell unless it crashed within 10 seconds of its own launch, the same crash-loop guard as the Linux handler.
  • SetThreadStackGuarantee(64 KiB) Every path is resolved at startup into fixed-size buffers, so the filter doesn't allocate; the stack guarantee leaves room to run after an overflow.

Services, in detail

  • SystemMonitor A native singleton behind the cheatsheet's System tab and the Resources desktop widget: host, OS and board, CPU usage and clocks, GPU and VRAM, RAM and page file, and every drive with its partitions.
  • WinRT on MTA threads Qt initializes COM as STA on the GUI thread, so init_apartment(multi_threaded) fails there with RPC_E_CHANGED_MODE and blocking .get() is forbidden. Every WinRT-backed service (GSMTC, Bluetooth, notifications, OCR) owns a worker thread in a multi-threaded apartment and posts results back to Qt.
  • UserNotificationListener Works unpackaged. NotificationChanged throws 0x80070490, so the mirror polls GetNotificationsAsync every 2 s; only text elements are exposed. One process per session owns the server (a named mutex); the others forward notifySend over WM_COPYDATA.
  • Shell_TrayWnd The hidden tray window passes every message on to Explorer, whose own tray keeps working, and mirrors Explorer's window properties (TaskbandHWND and others) every second so ITaskbarList3 keeps working for apps that show taskbar progress.

Colors and helpers

  • matugen.exe Run with ii's own template, so a wallpaper gives the same palette as on Linux. Windows' wallpaper and light/dark mode follow ii, and the accent color follows the palette.
  • TerminalColors A C++ port of ii's terminal color generator that matches the Python one bit for bit, written as a Windows Terminal fragment plus an Oh My Posh theme.
  • songrec.exe · LaTeX.exe SongRec 0.7.5's recognizer with a Windows front end (WASAPI loopback through cpal), and MicroTeX with its own Qt/SVG command line for LaTeX in the AI chat.
  • XMLHttpRequest Translation runs from QML instead of trans or curl.exe, which Google answered with an “unusual traffic” page.

Toolchain

  • clang-cl + lld-link Cross-compiled from Linux, with the MSVC CRT and SDK from xwin splat (C++/WinRT headers included) and CMake + Ninja. CMake links with lld-link directly, so no rc.exe or mt.exe is needed.
  • Qt 6.11.2 · msvc2022_64 Installed with aqtinstall, alongside a host gcc_64 build for the tools.
  • cargo-xwin Builds matugen 4.1.0 and the setup. The Visual C++ runtime DLLs ship inside the install folder, never in Windows' own folders.
  • Test targets Windows 11 25H2 VMs (with and without a passed-through GPU), a Windows 10 22H2 VM, and bare metal on an Intel i3-13100 with only its integrated GPU.

The setup

  • Tauri v2 Rust plus static HTML/CSS/JS, with no Node, bundler or CDN. The core crate, iiw-setup-core, is unit-tested on Linux: profile-block edits, versions, release JSON, SHA-256, zip, swap and rollback, manifest.
  • Per user Everything under %LOCALAPPDATA%, with no administrator rights except for the optional PowerShell 7. The package comes from the latest GitHub release and is checked against its published SHA-256 before anything is installed.
  • Self-update On every start the setup checks the latest release; if it's newer, it downloads the new setup, checks it against GitHub's SHA-256 digest and relaunches with it.
  • install-manifest.json Records every change so uninstall can undo it, including the wallpaper, light/dark mode, accent color and taskbar auto-hide captured before the first install. Repair moves settings to a dated backup and reinstalls stock.
  • --package <zip> Offline installs, or an ii-windows-<version>.zip next to the exe (verified too when its .sha256 is there).

Known limitations

  • Built on Windows' own APIs but barely tested: audio, media controls, battery, laptop brightness and music recognition (the VMs have no battery or laptop screen). New in 0.5.0 and so far tried only in VMs: Win + drag, the bar shrinking its applets at high scaling, game mode, the WARP toggle and the shutdown warnings.
  • Not on Windows: ii's lock screen (Win+L uses Windows' own), the EasyEffects toggle, and content-region detection in the region selector (no OpenCV).
  • Windows 10: ii can't remove virtual desktops and creates them by sending Ctrl+Win+D, the older blur has slightly jagged rounded corners, and Windows draws a yellow border around a screen recording.
  • Mirrored notifications carry text only: no images, launch arguments or buttons. Windows keeps showing its own banners too.
  • On Windows 10 the accent color from ii's palette doesn't stick; Windows keeps its own.
  • A panel shortcut pressed in the first second after the bar appears is ignored.
  • A few panels drop their rounded-corner masks on Windows for speed, so some content edges are clipped square and the overview thumbnails have no rounded corners.
  • The first start after an update is still slow: Defender and a cold disk go through every rewritten DLL, once per update.
  • While a window of an app running as administrator has the focus, Windows doesn't deliver the keyboard to ii's hook: ii's shortcuts don't work there and Win+Q opens Windows' search. Close those windows with Alt+F4.
  • While ii runs, taskbar tweaking tools that look for the taskbar by its window class may not find it.

Everything you'd expect from ii

The same QML as on Linux wherever it could stay the same, with Windows doing the work underneath.

  • Bar and system tray

    Media, clock, battery and the tray icons, shared with Explorer's own tray.

  • Sidebars

    Quick toggles, notifications and a calendar on the right; AI chat and a translator on the left.

  • Spotlight search

    Tap the Windows key for apps, files, clipboard history, emoji, system actions and the web in one box. Win+Tab opens the overview.

  • Colors from your wallpaper

    Material You palettes from matugen. Windows' accent color and light/dark mode follow along.

  • Workspaces and overview

    ii's workspaces are Windows' own virtual desktops, with live previews in the overview.

  • Tiling and Win + drag

    Hyprland's dwindle layout with ii's keybinds (off by default), and since 0.5.0 Win + drag moves windows and Win + right drag resizes them.

  • Screen tools

    Snip, copy text with on-device OCR, record to MP4 and translate what's on screen.

  • Notifications

    Toasts from other apps show up in ii's panel too, with a history.

  • Terminal look

    Windows Terminal and the classic console in ii's colors, with a Nerd Font prompt.

Get II for Windows

One setup installs, updates, repairs and uninstalls it.

Three steps

  1. Download ii-windows-setup.exe and run it.
  2. Read the page it shows: it lists everything it changes on your PC. Then pick your options.
  3. Install. Everything goes into your Windows user, with no administrator rights needed.
Download for Windows Latest release

To update, repair or uninstall later: Settings → Apps → Installed apps → illogical-impulse (ii-windows) → Modify. The setup also checks GitHub for a newer version every time it opens and updates itself first.

First shortcuts

  • WinSearch (pressed on its own)
  • Win+/Every keybind
  • Win+EnterTerminal

Requirements

  • Windows 11, build 22000 or newer.
  • Windows 10 version 2004 or newer (build 19041); 22H2 recommended. The setup needs the WebView2 Runtime there.
  • winget for the optional terminal tools and FFmpeg. On Windows 10 without it, the setup can install it.

What changes on my PC

The setup shows the full list before it installs anything. Here's the short version.

What gets installed

  • The program, about 210 MB, in %LOCALAPPDATA%\ii-windows. Nothing goes into Windows' own folders.
  • ii's own files in %LOCALAPPDATA%\quickshell\ii, replaced on every update. Your settings live apart, in %LOCALAPPDATA%\illogical-impulse, and updates never touch them.
  • Start menu shortcuts and an Apps entry called “illogical-impulse (ii-windows)”.
  • Options: start with Windows (on), the terminal setup with the JetBrainsMono Nerd Font, Oh My Posh, Starship and eza (on), PowerShell 7 (off), FFmpeg (off), and letting Windows PowerShell 5.1 run profile scripts, a security setting (off).

While ii runs

  • It takes over many Windows shortcuts: the Windows key alone opens ii's search, and Win+/ lists the rest. All of it stops when ii closes.
  • The Windows taskbar auto-hides and shows up when the pointer touches its edge. Auto-hide stays on between sessions, so the screen doesn't jump every time ii starts or closes; turning the hover-only taskbar off in ii's settings switches it back off.
  • Windows keeps drawing your wallpaper; ii only adds its widgets to the desktop, above your icons. Your desktop folder isn't changed.
  • Picking a wallpaper or light/dark mode in ii sets the same in Windows, changing the wallpaper in Windows recolors ii, and Windows' accent color follows ii's palette.
  • The translators send text to Google's translation service, and music recognition sends an audio fingerprint to Shazam, only when you use them.

Uninstall

  • Removes the program, ii's folders, the shortcuts, the Run entry and the Apps entry.
  • Takes ii's block out of your PowerShell profiles (with a backup) and puts the execution policy back if the setup changed it.
  • Uninstalls only the tools and fonts the setup installed itself.
  • Restores your wallpaper, light/dark mode, accent color and taskbar auto-hide.
  • Deletes your ii settings and saved API keys, unless you tick Keep my settings.

It can't undo virtual desktops, files you made (screenshots, recordings) or ordinary Windows settings you changed through ii, like volume, Wi-Fi or Bluetooth pairings.

Release notes

From Windows 11 only to Windows 10, native recording, tiling, Win + drag and a Spotlight search, in six days.

  1. 0.6.2 2026-10-08 Latest

    Faster everywhere, especially on weaker machines: the bar shows in about 2 seconds instead of 5 on the same slow VM, Settings opens inside ii already themed and translated in under a second, panels keep their window after the first open and the mouse hook only wakes ii when something under the pointer changes. About 45 MB lighter. Fixes external monitors being set back to full brightness on every start and translations not loading with the language on "auto".

  2. 0.6.1 2026-10-07

    The Settings app now has almost every option that used to live only in config.json (bar auto-hide, transparency and accent color, date formats, dock, on-screen keyboard, night light schedule, translator languages, search and more); options that only do something on Linux stay hidden. It's also translated to Brazilian Portuguese.

  3. 0.6.0 2026-10-07

    Starts much faster on weaker machines: on a VM held to two slow cores and a slow disk the bar shows in about 4 seconds instead of about 43. Spotlight search on the Windows key (apps, files, clipboard history, emoji, system actions and the web), with Win+Tab for the workspaces. A System tab in the cheatsheet with CPU, GPU, memory and disks, and CPU, RAM and disk cards for the desktop. Fixes mouse and keyboard lag on weaker machines, empty emoji search and crashes when ii reloaded mid-task.

  4. 0.5.0 2026-10-06

    Hold Win and drag to move a window, Win + right drag to resize it, with tiling and across monitors with different scaling. Windows draws the wallpaper again and ii only puts its widgets on the desktop; changing the wallpaper in Windows recolors ii. The bar shrinks its applets when they don't fit. Media visualizer, native color picker (Win+Shift+C), weather, game mode, the WARP toggle and a warning before shutting down while winget is installing. Fixes the bar sitting below the top or not reserving its space after a display scale change, and closing windows of apps running as administrator.

  5. 0.4.0 2026-10-05

    Optional tiling with Hyprland's dwindle layout on Windows' virtual desktops. The screen translator lays each translated paragraph over the original, desktop widgets sit next to the icons and can be dragged, tray icons of apps started before ii respond to clicks (Windows 10 included), and the classic console gets ii's colors and font. Fixes a crash in the Windows 10 virtual desktop helper, a second copy of ii starting on top of the first, and the bar losing its reserved space.

  6. 0.3.1 2026-10-05

    Windows 10's blur no longer shows as a band around the floating bar's rounded ends, and the setup's window opens in the free part of the screen.

  7. 0.3.0 2026-10-05

    Screen recording with Windows' own capture and encoder, no FFmpeg needed. ii's own system tray, shared with Explorer's. Wallpaper and widgets behind the desktop icons. Translation, music recognition and LaTeX in the AI chat. The setup updates itself from GitHub. Built on Quickshell 0.3.1 and the latest ii from end-4.

  8. 0.2.0 2026-10-02

    Windows 10 support (version 2004 or newer): virtual desktops, blur and the hover-only taskbar on any edge. The Visual C++ runtime is included, brightness works on laptop screens and dims in software elsewhere, and the setup checks for WebView2 and can install Windows Terminal and winget.

  9. 0.1.1 2026-10-02

    Fixes mouse and keyboard lag on real hardware: window events moved off ii's main thread and the mouse hook runs at high priority.

  10. 0.1.0 2026-10-02

    First release, Windows 11 only, with a setup that downloads the package, checks its SHA-256 and installs it for the current user.
