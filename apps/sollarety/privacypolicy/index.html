Privacy Policy

Last updated: October 5, 2026

The Bot does not read your messages. It does not request Discord's Message Content intent, which means Discord never sends it the text of messages. It cannot store, search or forward something it does not receive.

1. What is stored

Only these things outlast the moment they happen:

  • Warnings. When a moderator runs the warn command, the Bot saves the Discord user ID of the warned member, the user ID and tag of the moderator, the reason the moderator typed, the server ID, and the date. This is written to a file on the machine that hosts the Bot.
  • Moderation log messages. Each moderation action is posted as a message to a channel your administrators choose. That message lives in your server, under your control, like any other message.
  • Roblox account links. When you verify with the verify command, the Bot saves your Discord user ID together with your Roblox user ID, Roblox username and display name, the date your Roblox account was created, and the date you verified. This is written to a file on the machine that hosts the Bot, and it applies in every server that uses the Bot. It is created only when you complete the verification yourself.
  • Levels. In servers that turn levels on, the Bot keeps, for each member who chats there, their Discord user ID and the XP they have earned in that server. It counts that you sent a message — at most once a minute — and never what the message says. It also remembers if you turned off level-up DMs.
  • SOL$ wallets. If you use the economy commands, the Bot keeps your Discord user ID with your SOL$ balance, when you last claimed the daily reward and last worked, and your daily streak. The wallet is the same in every server that uses the economy. SOL$ is a virtual currency with no real-world value.

2. What is held only in memory

The Bot keeps a short buffer of its own console output so that administrators can diagnose failures without server access. It may contain user IDs and error messages. It is never written to disk and is erased every time the Bot restarts.

While music is playing, the Bot keeps the server's queue in memory: the title and link of each song and the user ID of whoever asked for it. The queue is dropped when the Bot leaves the voice channel. Tic-tac-toe games are likewise held in memory, and dropped when the game ends or after three minutes without a move.

3. What is read but not kept

To check role hierarchy before a punishment, and to answer the userinfo and serverinfo commands, the Bot reads roles, nicknames and join dates from Discord. That information is used to build the reply and then discarded — nothing is written down.

The purge command deletes messages through the Discord API. It does not read or copy their content before deleting.

To apply Roblox verification, the Bot reads from Roblox's public API the current name of a linked Roblox account, when it was created, and which Roblox groups it belongs to with which rank — the same things anyone can see on a Roblox profile. The answer is kept in memory for at most five minutes, to avoid asking twice, and is never written down.

When you use the play command, the link or search terms you typed are sent to the service they belong to — YouTube, SoundCloud or Spotify — from the machine that hosts the Bot, through the open-source yt-dlp program or, for Spotify, by reading Spotify's public embed page. A Spotify song is then looked up by its name and artist on SoundCloud or YouTube. Nothing that identifies you goes with any of these requests. YouTube audio is downloaded to a temporary folder on that machine, played into the voice channel, and deleted as soon as the song ends, is skipped, or the music is stopped. SoundCloud audio is streamed and never saved.

The roleplay commands ask the public nekos.best service for a random GIF of the action. The request names only the action; it carries nothing about you or your server.

4. What is never collected

  • message content, attachments or embeds;
  • direct messages;
  • voice audio — the Bot plays music into voice channels but never receives or records what anyone says;
  • email addresses, IP addresses, payment details or any real-world identity;
  • your Discord or Roblox password — both sign-ins happen on Discord's and Roblox's own sites;
  • anything at all from users who never appear in a moderation command, never verify a Roblox account, never chat in a server with levels turned on and never use the economy commands.

5. How long it is kept

Until a moderator deletes them. The delwarn command removes a warning permanently, and removing the Bot from your server stops any further records being created. There is no automatic expiry: a warning history that erased itself would defeat its own purpose.

A Roblox link is kept until you remove it with the unverify command, which deletes it at once, for every server. Removing the Bot from a server does not delete links: a link belongs to the person who made it, not to any one server.

XP is kept while the Bot is in the server — also while levels are turned off, so turning them back on picks up where it left off — and a wallet is kept until you ask for it to be deleted (section 8). Removing the Bot from a server does not delete the XP earned there; ask the Bot administrators if you want it gone.

6. Who can see it

Warnings are visible through the Bot only to members with the Moderate Members permission in the server the warning belongs to. A warning recorded in one server is not visible from another. The log channel is visible to whoever your administrators grant access to.

A Roblox link can be looked up with the whois command by members of any server that uses the Bot and that you are in — telling which Roblox account belongs to whom is what verification is for. Nobody else sees it.

Levels and SOL$ balances are visible to other members through the rank, leaderboard, balance and profile commands. The global leaderboards show your Discord name with your level or balance to members of every server that uses these features — but never which servers you are in.

Data is not sold, rented, or shared with third parties. There is no analytics service and no advertising.

7. Where it is stored

On a single self-hosted machine operated by the Bot's administrators. The stored data is not sent to any external service. Besides Discord's own API, the Bot talks to Roblox's public API and to the verification program described in section 12, and — for the music and roleplay commands described in section 3 — to YouTube, SoundCloud, Spotify's public embed pages and nekos.best. None of these requests carries what section 1 stores.

8. Your rights

You may ask what the Bot has recorded about you, and ask for it to be deleted, by contacting the Bot administrators through the official Discord server channels. Deleting a warning does not delete the message already posted in the server's log channel — that message belongs to your server, and a server administrator can remove it.

You can delete your own Roblox link at any time with the unverify command, without asking anyone.

You can turn level-up DMs off at any time with the No button on the DM or with the level-dms command. To have your XP or your wallet deleted, contact the Bot administrators as described above.

9. Children

The Bot is not directed at anyone under the minimum age required by the Discord Terms of Service in their country. It is not knowingly used to collect information from them.

10. Discord's own handling

Everything the Bot does passes through Discord, which handles your data under its own Privacy Policy. This policy covers only what the Bot itself does.

11. The invite page

The invite page at apps.daeese.me/sollarety/invite/ can sign you in with Discord so that it can show you which of your servers you are allowed to add the Bot to. That sign-in asks Discord for two things and nothing else: your username and avatar, and the list of servers you are in. It does not ask for your messages, and it grants the Bot no access to any server on its own.

What becomes of that data: a small program running at the network edge exchanges Discord's one-time code for a temporary access token, reads your name and server list once, and throws the token away when the request ends. Nothing is written to a database, a log or a file, because there is none to write to. The list travels back to your browser in the part of the URL after the #, which browsers never send to a server, and the page clears it from the address bar as soon as it has drawn the list. Closing the tab leaves nothing behind.

Signing in is optional. The same page offers an add without signing in link, which hands you straight to Discord's own server picker and tells this site nothing at all.

12. Roblox verification

The verify command sends you to a page at daeese.me that signs you in twice: first with Discord, to learn which Discord account is using the browser, and then with Roblox, through Roblox's official sign-in. The Discord sign-in asks only for your username. The Roblox sign-in asks only for your Roblox user ID, username, display name, account creation date and avatar link. The Bot never sees your password on either site.

What becomes of that data: a small program at the network edge exchanges each one-time code for a temporary token, reads the account details once, and revokes both tokens straight away, so no ongoing access to either account remains. It then holds the pair — your Discord user ID and your Roblox account details — for up to 30 minutes, until the Bot collects it. Collecting it deletes it. From then on the link lives only in the file described in section 1.

Between the two sign-ins, the page keeps a signed cookie in your browser for up to ten minutes, so it can tell that both sign-ins came from the same place. It holds no password or token, and it is deleted when the verification ends.

13. Changes

This policy may change. Material changes will be reflected here with a new "last updated" date.

14. Contact

Questions about this policy, or requests about your data, can be raised with the Bot administrators through the official Discord server channels.

Sollarety is a separate Discord application from ccore. They do not share storage, and ccore's privacy policy does not describe this Bot.
