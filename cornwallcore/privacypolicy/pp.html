1. Introduction

The ccore ("the Bot") is committed to protecting your privacy. This Privacy Policy explains how we collect, use, store, and protect your information when you use our Discord bot.

4. Data Storage and Retention

4.1 Message Storage
  • Messages are stored in memory for a maximum of 24 hours.
  • Storage exists solely for the message reposting feature.
  • The Bot does not keep a persistent database of messages.
  • Temporary storage is cleaned up automatically.
4.2 User Data
  • Discord information is kept only as long as necessary.
  • ROBLOX verification data is retained for roster management.
  • Command logs are stored temporarily for debugging and security.
4.3 Data Minimization
  • We collect only what is necessary for Bot functionality.
  • No unnecessary personal data is collected or retained.
  • Message content is not permanently stored.

5. Data Sharing and Disclosure

No third-party sharing
We do not sell, rent, or share personal information for advertising or commercial purposes.
Limited disclosure
Disclosure may occur only for legal, security, or service-provider reasons.

5.3 Regimental Management

  • ROBLOX verification information may be used for roster management.
  • User role assignments may be visible to server administrators with appropriate permissions.

6. Data Security

6.1 Technical Measures

  • Encryption through Discord's secure connections.
  • Access controls for Bot systems and data.
  • Memory management for temporary message storage.
  • Secure logging without sensitive information exposure.

6.2 Administrative Measures

  • Limited access for authorized administrators only.
  • Regular security reviews and data handling checks.
  • Training on privacy and security best practices.

7. Your Rights and Choices

7.1 Data Access

You can request information about what data we have about you by contacting the Bot administrators.

7.2 Data Correction

You can request updates to incorrect ROBLOX or other information through the administrators.

7.3 Message Control

Messages are removed automatically after 24 hours, and manual deletion requests can be made through administrators.

7.4 Bot Usage

You can stop using the Bot at any time and request removal from regimental systems if applicable.

8. Message Reposting Privacy

8.1 How It Works

  • Messages are temporarily stored for automatic reposting functionality.
  • Reposting occurs randomly in designated channels.
  • Bot messages and system messages are automatically excluded.

8.2 Your Control

  • Messages are automatically removed from storage after 24 hours.
  • You can request immediate deletion of your stored messages.
  • Server administrators can disable the reposting feature.

8.3 Limitations

  • Once reposted, messages become part of Discord's permanent chat history.
  • The Bot cannot delete messages from Discord's servers.
  • Original messages remain in Discord regardless of Bot storage.

9. Children's Privacy

16. Local AI

Some optional features use a language model that runs on a machine of the Bot operators, not on an outside AI service. The operators turn it on and off, and while it is off nothing is sent to it. The same model also serves Sollarety, another bot run by the same operators; no conversation passes between the two bots.

  • Chat: when you mention the Bot or reply to one of its messages, the text of your message, your display name and the last few messages of that channel, with their authors' display names, are sent to the model so it can write the reply, which is posted in the channel.
  • Translate and /resumo: the message you pick, or the last 10 to 100 messages of the channel, are sent to the model. The result is shown only to you.
  • /desempenho: your audit numbers are sent so the model can comment on them. The numbers shown come from the audit, not from the model.
  • /anuncio and the after-action report: the topics you wrote, or the names and kills, deaths and assists of the battle just recorded, are sent to the model. The announcement is posted only if you confirm it; the report is posted in the channel where the battle was recorded.
  • Convert with AI: the text you pasted in /audit-add is sent to the model and the rewritten text is shown only to you. Nothing is recorded until you send it again yourself.

Nothing sent to the model is written to disk. The model keeps the latest request in memory only to answer faster, and loses it with the next request or when it restarts. To space out questions and stop spam, the Bot also remembers, in memory and for a few minutes, when each person last talked to it. Replies are generated automatically and can be wrong.
