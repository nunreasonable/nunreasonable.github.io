SOLLARETY

Moderation, warnings, fun and utility - in one Discord bot.

Add to a server

Sign in with Discord and this page will list the servers where you are allowed to add a bot, so you can pick one instead of hunting through a dropdown. Nothing you do here is stored.

Permissions to request

Add without signing in

Signing in asks Discord for your username and the list of servers you are in - nothing else, and never your messages. The list is read once, shown to you, and thrown away; it is not saved on any server, including this one. "Add without signing in" skips that entirely and lets Discord's own picker choose the server.

Choose a server

 
Pick a server to add Sollarety to.

None of your servers can take a new bot. Adding one needs the Manage Server permission, so only servers you own or help run are listed here.

Done

Sollarety is in. Type /help in the server to see every command. If the slash commands do not appear right away, give Discord up to an hour to propagate them.
